# DocumentFindHasExpiredRecipients

Filter for documents that have at least one recipient whose signing link has expired.

## Example Usage

```python
from documenso_sdk.models import DocumentFindHasExpiredRecipients

value = DocumentFindHasExpiredRecipients.TRUE
```


## Values

| Name    | Value   |
| ------- | ------- |
| `TRUE`  | true    |
| `FALSE` | false   |
