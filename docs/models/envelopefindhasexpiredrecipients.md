# EnvelopeFindHasExpiredRecipients

Filter for envelopes that have at least one recipient whose signing link has expired.

```python
from documenso_sdk.models import EnvelopeFindHasExpiredRecipients

value = EnvelopeFindHasExpiredRecipients.TRUE
```
